## 2. 文件管理

### 2.1 浏览文件

1. 点击左侧导航栏的「文件」进入文件管理页面
2. 点击文件夹进入子目录
3. 使用面包屑导航快速返回上级目录
4. 点击「显示隐藏文件」查看隐藏文件

### 2.2 上传文件

**方式一：点击上传**
1. 点击工具栏的「上传」按钮
2. 选择要上传的文件
3. 等待上传完成

**方式二：拖拽上传**
1. 将文件从电脑拖拽到文件列表区域
2. 松开鼠标完成上传

### 2.3 下载文件

1. 找到要下载的文件
2. 右键点击文件，选择「下载」
3. 或点击文件右侧的下载图标

### 2.4 创建文件夹

1. 点击工具栏的「新建文件夹」按钮
2. 输入文件夹名称
3. 点击「确定」创建

### 2.5 重命名

1. 右键点击文件/文件夹
2. 选择「重命名」
3. 输入新名称
4. 按 Enter 或点击确定

### 2.6 移动/复制

1. 选择要操作的文件（可多选）
2. 右键选择「移动到」或「复制到」
3. 在弹出的目录选择器中选择目标位置
4. 点击「确定」完成操作

### 2.7 删除文件

**移至回收站（软删除）：**
1. 选择要删除的文件
2. 右键选择「删除」或按 Delete 键
3. 文件将移至回收站

**永久删除：**
1. 选择要删除的文件
2. 右键选择「永久删除」
3. 确认删除操作

### 2.8 回收站

1. 点击左侧导航的「回收站」
2. 查看已删除的文件
3. 选择文件后可以：
   - 「恢复」- 恢复到原位置
   - 「永久删除」- 彻底删除
4. 点击「清空回收站」删除所有文件

### 2.9 搜索文件

1. 在顶部搜索框输入关键词
2. 按 Enter 或点击搜索图标
3. 可使用筛选条件：
   - 文件类型：文件/文件夹
   - 文件扩展名
   - 搜索路径

## 3. 文件分享

### 3.1 创建分享

1. 右键点击要分享的文件/文件夹
2. 选择「创建分享」
3. 配置分享选项：
   - **访问类型**：
     - 公开访问：任何人可访问
     - 密码保护：需要输入密码
   - **过期时间**：设置分享链接的有效期
   - **下载限制**：设置最大下载次数
4. 点击「创建」生成分享链接
5. 复制链接发送给他人

### 3.2 管理分享

1. 点击左侧导航的「分享」
2. 查看所有已创建的分享
3. 可以进行以下操作：
   - 复制分享链接
   - 编辑分享设置
   - 禁用/启用分享
   - 删除分享
   - 重新生成分享码

### 3.3 访问分享

**访问者操作：**
1. 打开分享链接
2. 如果需要密码，输入密码验证
3. 查看文件信息
4. 点击「下载」获取文件
5. 如果是文件夹分享，可以浏览文件夹内容

## 4. 文件版本

### 4.1 查看版本历史

1. 右键点击文件
2. 选择「版本历史」
3. 查看所有历史版本列表

### 4.2 下载历史版本

1. 在版本历史列表中找到目标版本
2. 点击「下载」按钮

### 4.3 恢复到历史版本

1. 在版本历史列表中找到目标版本
2. 点击「恢复」按钮
3. 确认恢复操作
4. 当前文件将被替换为历史版本

### 4.4 比较版本

1. 在版本历史中选择两个版本
2. 点击「比较」按钮
3. 查看版本差异信息

## 5. 用户管理（管理员）

### 5.1 查看用户列表

1. 点击左侧导航的「用户」
2. 查看所有用户列表
3. 使用搜索框筛选用户

### 5.2 创建用户

1. 点击「新建用户」按钮
2. 填写用户信息：
   - 用户名（必填）
   - 密码（必填）
   - 显示名称
   - 邮箱
   - 角色
   - 存储配额
3. 点击「创建」

### 5.3 编辑用户

1. 在用户列表中找到目标用户
2. 点击「编辑」按钮
3. 修改用户信息
4. 点击「保存」

### 5.4 用户角色说明

| 角色 | 权限 |
|------|------|
| SuperAdmin | 超级管理员，拥有所有权限，不可删除 |
| Admin | 管理员，可管理用户、存储、系统设置 |
| PowerUser | 高级用户，扩展的文件操作权限 |
| User | 普通用户，基本文件操作权限 |

### 5.5 重置密码

1. 在用户列表中找到目标用户
2. 点击「重置密码」
3. 输入新密码
4. 点击「确定」

### 5.6 禁用/启用用户

1. 在用户列表中找到目标用户
2. 点击状态开关切换启用状态
3. 禁用的用户无法登录系统

## 6. 存储管理（管理员）

### 6.1 存储概览

1. 点击左侧导航的「存储」
2. 查看存储使用概览：
   - 总容量
   - 已使用
   - 可用空间
   - 使用率

### 6.2 存储池管理

**创建存储池：**
1. 点击「新建存储池」
2. 填写信息：
   - 名称
   - 存储路径（选择系统目录）
   - 描述
   - 容量限制（可选）
3. 点击「创建」

**编辑存储池：**
1. 在存储池列表中点击「编辑」
2. 修改配置
3. 点击「保存」

**设置默认存储池：**
1. 在存储池列表中找到目标存储池
2. 点击「设为默认」

### 6.3 刷新容量信息

点击「刷新」按钮更新存储池的容量信息

## 10. 常见问题

### Q1: 上传文件失败怎么办？

**可能原因：**
- 文件过大超出限制
- 存储空间不足
- 网络连接问题

**解决方案：**
1. 检查文件大小是否超出限制
2. 检查存储空间是否充足
3. 刷新页面重试
4. 检查网络连接

### Q2: 无法删除文件？

**可能原因：**
- 文件被其他程序占用
- 没有删除权限

**解决方案：**
1. 确认文件未被其他程序使用
2. 联系管理员检查权限

### Q3: 分享链接无法访问？

**可能原因：**
- 分享已过期
- 分享已被禁用
- 下载次数已达上限

**解决方案：**
1. 检查分享设置
2. 重新创建分享

### Q4: 忘记密码怎么办？

**解决方案：**
1. 联系系统管理员重置密码
2. 管理员可在用户管理中重置密码
