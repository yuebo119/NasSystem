## 口径声明

- 绝对值仅在本机本轮有效，跨机器只比较比值。
- 读用例两臂共享同一份库；写用例在可复用库上进行，每次迭代前做一次不计入测量的重置。
- 数据访问层不含 DI 与 HTTP 管线，端到端差异看 API 段。
- 地板臂为裸 ADO.NET 等价 SQL，不构造领域对象，是上限参照而非竞品。
